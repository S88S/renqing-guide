# 县城人情指南

> 45 条人情账本的不变法则 · 把握本质 · 跨越周期
>
> 每个场景点出「不变的本质」——行为会过时，本质传得下去。写给县城青年，也写给二十年后的孩子。

## 这是一本什么书

进入社会，人情这门课没有教材。随礼随多少？借钱怎么开口？拒绝怎么不伤人？饭局怎么坐、话怎么说？——事是小的，账是大的，人一辈子的名声、交情、路子，就是这么一笔一笔攒出来的。

市面上讲人情世故的东西不少，但大多犯两个毛病：要么把它骂成"陋习"，要么把它吹成"厚黑"。**人情世故没有好坏，只有国情**——全世界都有人情往来（美国的 networking、日本的义理人情），到了中国县城，它叫随礼、叫面子、叫还情。它是水，你是鱼，鱼讨论水好不好喝，不如先学会游。

这本书要做一件同类书没做的事：**把握本质，跨越周期**。社会在变——随礼从登门送被面变成微信红包，办事从跑三趟变成打一个电话。外在表现一直在变，但账本的逻辑从没变过。所以每个条目都有一段「不变的本质」：告诉你"变的是形式，不变的是什么"。**行为会过时，本质传得下去。**

## 特色

- **每条带「不变的本质」**：全书灵魂字段。先读这一句，再看具体做法
- **话术可抄**：「可以怎么说」全是口语化示例（带称呼），改几个字就能用
- **代价明码**：「代价账」讲清这笔人情花了什么、换回什么、过头了会怎样
- **依据三级标注**：〔古籍〕〔现代书〕〔经验〕——哪些经过时间检验，哪些一家之言，明明白白
- **娓娓道来**：不教厚黑、不灌鸡汤、不上价值，像有阅历的老大哥围着炉子说话
- **三条底线**开宗明义：法律纪律 / 不害人 / 不委屈自己

## 怎么用

1. **遇到具体场景直接查**，不必从头读。每条独立成篇
2. 先读每条的「不变的本质」，再看做法——**记本质不记做法**，做法会过时
3. 「可以怎么说」是参考不是剧本，换成你自己的口气
4. 数字类信息（随礼行情等）均以当地为准——县城之间差别很大
